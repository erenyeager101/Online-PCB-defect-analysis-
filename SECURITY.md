# Security Policy

## Supported Versions

We aim to keep the main branch secure and maintained. If you discover a security vulnerability, please follow the steps below.

## Reporting a Vulnerability

- Do NOT create a public GitHub issue for security vulnerabilities.
- Instead, please report privately to the maintainers.
- If maintainers are not listed, open a discussion requesting a private contact channel without revealing details.

Please include:
- A description of the issue and potential impact
- Steps to reproduce
- Any known mitigations or workarounds

We appreciate responsible disclosure to keep users safe.
