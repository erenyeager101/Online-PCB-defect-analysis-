About This Application

This tool performs real-time PCB defect classification using a pre-trained deep learning model. It also provides an explainability overlay (Grad-CAM) to highlight influential regions.

Fast Inference

Optimized preprocessing enables quick, single-image predictions with confidence scoring.

Explainability

Grad-CAM visualization reveals where the network focuses when identifying defects.

Secure Uploads

Files are sanitized and stored with unique IDs to prevent collisions and overwrites.

How It Works

  1. Upload a PCB image (JPEG/PNG).
  2. The model predicts defect presence and returns a label + confidence.
  3. Grad-CAM highlights regions contributing most to the prediction.
